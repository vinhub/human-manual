# The Human Manual

**Working subtitle:** An Engineer's Manual for Thinking and Living

## Purpose

A science-informed, reason-first curriculum for understanding reality, understanding ourselves, thinking clearly, navigating society, and living a meaningful life.

The project is designed as a **knowledge system first** and a book second. Each concept should stand alone, connect to other concepts, and be reusable across:

- Website
- Book
- YouTube
- Instagram
- Newsletter
- Courses
- Chatbot / AI tutor

## Core principle

> Understand reality → understand life → understand mind → improve reasoning → understand society → decide what matters → practice living.

## Editorial standard

Prefer:
- Evidence over authority
- Reason over rhetoric
- Explicit uncertainty over false certainty
- Mechanisms over slogans
- Examples over abstraction
- Steelmanning over caricature
- "I don't know" when warranted

Avoid presenting philosophical or scientific claims as established fact merely because they are interesting.
